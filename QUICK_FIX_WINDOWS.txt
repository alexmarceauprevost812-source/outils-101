❌ SI TU AS UNE ERREUR
═══════════════════════════════════════════════════════════════════════════════

ERREUR 1 : "Python n'est pas reconnu"
────────────────────────────────────────────────────────────────────────────────
Solution :
1. Télécharge Python : https://www.python.org/downloads/
2. Lance l'installateur
3. ⚠️  COCHE "Add Python to PATH"
4. Redémarre ton PC
5. Relance WINDOWS_COMMANDS.bat

ERREUR 2 : "OSError: Npcap is not installed"
────────────────────────────────────────────────────────────────────────────────
Solution :
1. Télécharge Npcap : https://npcap.com/download/
2. Lance l'installateur
3. ⚠️  COCHE "Install Npcap in WinPcap API-compatible Mode"
4. Redémarre ton PC
5. Relance WINDOWS_COMMANDS.bat

ERREUR 3 : "Access denied" ou "Permission denied"
────────────────────────────────────────────────────────────────────────────────
Solution :
- Lance TOUJOURS les scripts EN ADMINISTRATEUR
- Clic droit sur le fichier > "Exécuter en tant qu'administrateur"

ERREUR 4 : "Git n'est pas installé"
────────────────────────────────────────────────────────────────────────────────
Solution :
1. Télécharge Git : https://git-scm.com/download/win
2. Lance l'installateur
3. Redémarre ton PC
4. Relance WINDOWS_COMMANDS.bat

ERREUR 5 : "No module named 'scapy'"
────────────────────────────────────────────────────────────────────────────────
Solution :
1. Ouvre Command Prompt EN ADMINISTRATEUR
2. Tape : pip install scapy requests
3. Attends la fin
4. Relance : python main.py

ERREUR 6 : "Je suis dans un dossier avec des espaces"
────────────────────────────────────────────────────────────────────────────────
Exemple du problème :
  C:\Users\alex marceau\Desktop\source  ← "alex marceau" a un espace ❌

Solution :
  Utilise des guillemets :
  cd "C:\Users\alex marceau\Desktop\source"

  Ou crée un dossier sans espaces :
  C:\Dev\source  ✅

✅ VÉRIFIER QUE TOUT MARCHE
═══════════════════════════════════════════════════════════════════════════════

Test 1 - Vérifier Python
────────────────────────────────────────────────────────────────────────────────
1. Ouvre Command Prompt
2. Tape : python --version
3. Doit afficher : Python 3.8.0 (ou plus récent) ✅

Test 2 - Vérifier Npcap
────────────────────────────────────────────────────────────────────────────────
1. Ouvre Command Prompt
2. Tape : npcap-config --version
3. Doit afficher un numéro de version ✅

Test 3 - Vérifier Scapy
────────────────────────────────────────────────────────────────────────────────
1. Ouvre Command Prompt
2. Tape : python -c "import scapy; print('OK')"
3. Doit afficher : OK ✅
