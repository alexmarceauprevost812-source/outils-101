═══════════════════════════════════════════════════════════════════════════════
❌ "PYTHON N'EST PAS RECONNU COMME UNE COMMANDE INTERNE"
═══════════════════════════════════════════════════════════════════════════════

Erreur complète:
  'python' is not recognized as an internal or external command

Cause:
  Python n'est pas installé OU pas dans PATH

Solution:
  1. Télécharge Python : https://www.python.org/downloads/
  2. Lance l'installateur
  3. ⚠️ COCHEZ "Add Python to PATH" (IMPORTANT!)
  4. Redémarre ton PC
  5. Vérifie : tape "python --version"
  6. Doit afficher "Python 3.x.x"

Si ça marche pas :
  1. Réinstalle Python
  2. Cette fois, PENDANT L'INSTALLATION:
     - Coche "Add Python to PATH"
     - Coche "Install for all users"
  3. Redémarre ton PC

❌ "OSERROR: NPCAP IS NOT INSTALLED OR NOT IN THE PATH"
═══════════════════════════════════════════════════════════════════════════════

Erreur complète:
  OSError: Npcap is not installed or not in the PATH

Cause:
  Npcap (le driver réseau) n'est pas installé

Solution:
  1. Télécharge Npcap : https://npcap.com/download/
  2. Lance l'installateur (.exe)
  3. ⚠️ COCHEZ "Install Npcap in WinPcap API-compatible Mode"
  4. Termine l'installation
  5. ⚠️ REDÉMARRE TON PC (IMPORTANT!)
  6. Réessaie l'outil

Important:
  - Cette erreur signifie que ton outil ne peut pas scanner le réseau
  - Npcap est OBLIGATOIRE pour qu'Outils 101 marche
  - Prend 3 minutes à installer

═══════════════════════════════════════════════════════════════════════════════
❌ "NO MODULE NAMED 'SCAPY'"
═══════════════════════════════════════════════════════════════════════════════

Erreur complète:
  ModuleNotFoundError: No module named 'scapy'
  OU
  ImportError: No module named scapy

Cause:
  Les dépendances Python ne sont pas installées

Solution:
  1. Ouvre Command Prompt EN ADMINISTRATEUR
  2. Tape ceci (puis Entrée):
     pip install scapy requests
  3. Attends que ça finisse (1-2 minutes)
  4. Doit afficher "Successfully installed..."
  5. Relance l'outil : python main.py

Si ça marche pas:
  1. Tape : pip install --upgrade pip
  2. Puis : pip install scapy requests
  3. Puis réessaie : python main.py

❌ "DIRECTORY ALREADY EXISTS"
═══════════════════════════════════════════════════════════════════════════════

Erreur complète:

Cause:
  Tu as déjà cloné le repo une fois

Solution:

    1. Va dans le dossier "source" existant
    2. Tape : cd source
    3. Tape : git pull
    4. Cela met à jour le code

  Option 2 (réinstaller):
    1. Supprime le dossier "source" entièrement
    2. Relance : git clone https://github.com/Alexmarceauprevost812/source.git
    3. cd source
    4. pip install -r requirements.txt


═══════════════════════════════════════════════════════════════════════════════
❌ "NE PEUT PAS ENTRER DANS LE DOSSIER"
═══════════════════════════════════════════════════════════════════════════════

Erreur complète:
  The system cannot find the path specified.
  OU
  No such file or directory

Cause:
  Le chemin n'existe pas ou le dossier n'a pas été créé

Solution:
  1. Crée le dossier manuellement:
     mkdir C:\Dev
  2. Va dedans:
     cd C:\Dev
  3. Clone le repo:
     git clone https://github.com/Alexmarceauprevost812/source.git
  4. Va dans le dossier:
     cd source
  5. Installe:
     pip install -r requirements.txt

Attention à l'espace:
  Si ton dossier contient des espaces (ex: "C:\Users\Alex Marceau")
  Mets-le entre guillemets:
    cd "C:\Users\Alex Marceau\Desktop"

❌ "CERTIFICAT SSL INVALIDE"
═══════════════════════════════════════════════════════════════════════════════

Erreur complète:
  SSL: CERTIFICATE_VERIFY_FAILED
  OU
  certificate verify failed

Cause:
  Problème de certificat SSL (rare)

Solution:
  1. Ouvre Command Prompt EN ADMINISTRATEUR
  2. Tape:
     pip install --trusted-host pypi.org --trusted-host files.pythonhosted.org scapy requests
  3. Attends la fin
  4. Réessaie : python main.py

Alternatif:
  1. Désactive temporairement l'antivirus
  2. Réessaie l'installation
  3. Réactive-le après

═══════════════════════════════════════════════════════════════════════════════
❌ "POWERSHELL REFUSE DE LANCER LE SCRIPT"
═══════════════════════════════════════════════════════════════════════════════

Erreur complète:
  cannot be loaded because running scripts is disabled on this system

Solution:
  1. Ouvre PowerShell EN ADMINISTRATEUR
  2. Tape ceci (puis Entrée):
     Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
  3. Réponds "Y" (Yes) si demandé
  4. Maintenant relance le script:
     .\install.ps1
  5. Suis les étapes
