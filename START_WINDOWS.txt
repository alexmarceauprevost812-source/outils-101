1️⃣  Python 3.8+

   Résultat : Npcap version 1.x.x ✅

   Si ❌ : Télécharge https://npcap.com/download/
          COCHE "Install Npcap in WinPcap API-compatible Mode"
          REDÉMARRE TON PC

═══════════════════════════════════════════════════════════════════════════════
❌ J'AI UNE ERREUR
═══════════════════════════════════════════════════════════════════════════════

Erreur : "Python n'est pas reconnu"
Cause : Python pas installé ou pas dans PATH
Solution :
  - Télécharge https://www.python.org/downloads/
  - COCHE "Add Python to PATH"
  - Redémarre ton PC

Erreur : "OSError: Npcap is not installed"
Cause : Npcap pas installé ou mal configuré
Solution :
  - Télécharge https://npcap.com/download/
  - COCHE "Install Npcap in WinPcap API-compatible Mode"
  - Redémarre ton PC

Erreur : "Access denied" ou "Permission denied"
Cause : Pas lancé en administrateur
Solution :
  - TOUJOURS lancer en ADMINISTRATEUR
  - Clic droit > "Exécuter en tant qu'administrateur"

Erreur : "Git n'est pas installé"
Cause : Git pas installé
Solution :
  - Télécharge https://git-scm.com/download/win
  - Redémarre après installation

Erreur : "No module named 'scapy'"
Cause : Dépendances Python non installées
Solution :
  - Command Prompt EN ADMINISTRATEUR
  - Tape : pip install scapy requests
  - Relance : python main.py

Pour d'autres erreurs :
  → Lis QUICK_FIX_WINDOWS.txt
  → Ou WINDOWS_INSTALL_SIMPLE.md
